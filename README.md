# 英雄棒球大戰（殺人棒球）

東方眾神對上西方眾神的超能力棒球手機遊戲。東方神將隊（孫悟空、須佐之男、哪吒、九尾狐……）對上西方神祇隊（宙斯、海克力士、索爾、雅典娜……），兩隊共 24 位英雄，每個人都有自己的打擊或投球姿勢、專屬氣場、必殺技和被動能力。觸身球、強襲球、衝撞和必殺技都會造成傷害，體力歸零就被擊倒退場，場上能打的人少於 6 人直接輸掉比賽。

比賽中會遇到宿敵對決、覺醒、關鍵時刻和天候異變（暴雨、雷雨、強風、濃霧），還有實況字幕、飛身撲接、沒收全壘打、必殺技特寫，以及兩隊各自的應援曲。

**線上玩：** https://gajuioredvmn.github.io/hero-baseball/

## 操作

- **打擊**：球進本壘板那一刻按下螢幕。打中時畫面變慢、出現力氣條；手指按住往左右滑決定打向左外野或右外野，往上滑打高飛球、往下滑打滾地球，放開手指那一刻決定力氣。
- **投球**：先選球種，再從螢幕下方往上畫出球路，放開手指的位置就是進壘點。球會照畫的形狀跑，能彎多少看球種和投手的變化能力；球速看投手能力和球種。
- **必殺技**：必殺槽集滿後點「必殺」，照著符號畫一筆就能發動。
- **守備**：野手會自己追球；接到球時點畫面上的壘包決定傳哪一壘。
- **跑壘**：點「衝！」或「退回」指揮跑者；投手出手前點右下角小鑽石上的壘包可以盜壘。
- 暫停選單可以切換畫質、音效和音樂。

## 開發

```
python3 build.py src/main.js dist/index.html   # 把 src/ 串成單一檔案
cp dist/index.html index.html                   # 根目錄的 index.html 就是 GitHub Pages 上線的版本
```

- `src/*.js` 依 `build.py` 裡的 `ORDER` 串接成一個 IIFE；`src/head.html`、`src/body.html`、`src/style.css` 是頁面骨架與樣式。
- 自製 WebGL2 繪圖（像素角色、球場、景深與光暈），不依賴外部函式庫；音效與應援曲都是 Web Audio 即時合成。
- `test/` 是開發用的測試腳本：Playwright 截圖、模擬玩家操作的機器人、無頭的電腦對打模擬（檢查平衡）。

純原創美術與音效，沒有使用受版權保護的素材。
